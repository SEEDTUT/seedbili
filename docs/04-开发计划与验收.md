## 三、体积（1.1.6 实测）

| 项 | 实测 |
|---|---|
| jlink 运行时（10 模块，strip 原生命令） | 63MB |
| skiko 原生库（dll 13.5 + runtime jar 10.1 + icudtl 10） | 约 34MB |
| 应用 jar + 三方依赖 | 49.4MB |
| 装完合计（`%LOCALAPPDATA%\ReplyAgent`） | 137MB |
| MSI | 80.6MiB（84,525,480 B） |
| EXE | 81.5MiB（85,446,656 B） |
| 沙箱（可选，另计） | 首次安装 200–400MB（Debian），之后常驻 |

`material-icons-extended` 原本 36MB（5 套风格 × 2000+ 图标），构建时只保留 rounded 一套（7.7MB），
MSI 从 107.9MB 降到 80.6MB。**不要改成手写图标白名单**：漏掉一个（QrCode2）就是启动即崩
`ClassNotFoundException`，按风格整体保留最稳。skiko 的三份文件一个都不能删，删了窗口直接起不来。

## 四、已知限制（不藏）

1. 首版无定时轮询、无动态/专栏支持。
2. B 站接口无官方承诺，WBI 签名与风控码可能随对方改版失效 → 已把接口层集中封装，改版时只动 `platform/bilibili/`。
3. 「工具内置浏览器显示登录页」被替换为扫码登录（⚠ 见 `05-待确认清单.md` 第 1 条）。
4. 环境自动安装依赖 `wsl.exe`：企业组策略禁用、或精简系统删掉 WSL 时脚本会失败并回退到手动命令，不会假装成功。
5. 同版本 MSI 覆盖安装会被 Windows 拒绝（1638），升级必须涨版本号。
6. 体积未达「越小越好」的理想到 Flutter 量级，是 JVM 换打包/进程能力的代价。
